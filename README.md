## 📝 How to Update

### Add Your Profile Picture
1. Save your photo as **`profile.jpg`**
2. Go to: https://github.com/GworldAnalytics/GworldAnalytics.Github.io
3. Click **"Add file"** → **"Upload files"**
4. Upload `profile.jpg`
5. Commit

### Upload Your CV
1. Save your CV as **`CV.pdf`**
2. Go to your repository
3. Click **"Add file"** → **"Upload files"**
4. Upload `CV.pdf`
5. Commit

### Update Project Information
Edit the 6 project cards in `index.html`:
- Replace "Project 1, 2, 3..." with your project names
- Add project descriptions
- List tools used
- Add project links
